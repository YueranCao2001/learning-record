# 学习主题索引

每日笔记仍保存在 `daily/YYYY/MM/`，这里按主题链接原文，不移动、复制或替代日期记录。每篇笔记按主要内容归入一类；需要时通过相关主题链接交叉阅读。

## 分类入口

- [Transformer 基础与生成](transformer-foundations.md)。Attention、位置机制、解码器结构、KV Cache 与采样。沿着张量形状和数据流理解模型前向与逐步生成。
- [训练与数据工程](training-engineering.md)。训练目标、优化步骤、显存、并行、性能、数据流水线及异常恢复。关注数值正确性与执行效率。
- [后训练与偏好优化](post-training.md)。SFT、DPO、PPO 与 GRPO、Rollout 和奖励评估器。当前记录以概念及合成验证为主，真实模型训练的完成状态需要实际产物支持。
- [评估与实验方法](evaluation-experiments.md)。Checkpoint 评估、小模型实验设计、统计解释、消融与可复现报告。用于检验其他主题的改进，而不只服务于一个算法。
- [推理部署与工具执行](inference-tools.md)。服务验收、调度、KV 块管理、量化、投机解码、结构化输出及可靠工具调用。区分算法性质、系统正确性与实测性能。
- [RAG 检索与应用工程](rag.md)。检索、证据、引用、评估、安全和运行治理。当前实践主线是将已有局部练习收拢到同一个可运行的小项目。

## 维护方式

新增每日记录时，同时更新仓库 README 日期列表和对应主题索引。分类标题不代表掌握程度；实测、合成验证与计划中的任务必须分别记录。

主题页用于归纳稳定结论、串联相关笔记和维护阶段状态。修正旧理解时保留原日期文件，在相关笔记中注明修正依据，并更新主题页的结论。
