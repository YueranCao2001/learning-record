# 2026-11-05：中文信息抽取微调：时间漏抽的同源诊断

## 今日目标

复现[昨天的等步数训练](2026-11-04-sft-venue-cue-comparison.md)中新出现的时间漏抽。固定同一活动及明确时间，检查相邻的地点称谓、未定措辞和分句顺序变化后，三份权重会怎样输出。

## 核心概念

- 地点的缺失标签只决定 `location`。同一通知若明确给出时间，仍应保留完整的时间片段。
- 先重跑冻结原题，再看同源改写。重跑时比较完整的生成 token；改写则按标注规则比较三个字段。
- 同一来源的改写用于定位触发表述。它们共享活动、模板和标签，样例数与来源数应分开统计。

## 示例与练习

### 1. 复现与改写

“竹编体验班”原题覆盖时间有无与地点有无的四个组合。发生退化的版本包含以下两行，期望 `time` 为 `"周日下午15:00"`、`location` 为 `null`。

```text
一、会址：后续发布
二、日程：周日下午15:00
```

在这条原题上，只将“会址”换成“地点”、只将“后续发布”换成“尚未确定”、同时替换两处，最后另做一个把日程移到第一项的版本。换序时编号仍随行位置，两个字段内容和预期标签固定。[冻结协议](../../../practice/sft-extraction/data/time-regression-v1.json) · [完整输入](../../../practice/sft-extraction/results/2026-11-05-time-regression-v1/cases.json)

### 2. 同分背后的字段变化

三份权重对四条原题的 12 份输出均逐 token 复现。明确时间和地点都给出的原题，三份权重都抽对。地点明确而时间未定、两者均未定的原题也都抽对。

下面五条的期望时间均为“周日下午15:00”，地点均为 `null`。统一称谓组与保留原称谓组在这 8 条样例上的解析结果相同。

| 输入变化 | 36 步起点的时间 / 地点 | 昨天两组的时间 / 地点 |
| --- | --- | --- |
| 原句“会址：后续发布” | 完整时间 / `null` | `null` / `null` |
| 仅换称谓“地点：后续发布” | 完整时间 / “后续发布” | 完整时间 / `null` |
| 仅换措辞“会址：尚未确定” | 完整时间 / `null` | 完整时间 / `null` |
| 两处都换“地点：尚未确定” | 完整时间 / “尚未确定” | 完整时间 / `null` |
| 保留“会址：后续发布”，日程放第一项 | 完整时间 / `null` | `null` / `null` |

三份权重的整条正确数均为 6/8，活动名和字段格式均为 8/8。起点的时间为 8/8、地点为 6/8。昨天两组的时间为 6/8、地点为 8/8，错误从两条地点误抽换成两条时间漏抽。只换称谓或未定措辞在这条通知上都能让两组恢复时间，交换行序仍漏抽。[逐题结果](../../../practice/sft-extraction/results/2026-11-05-time-regression-v1/review.json)

## 遇到的问题

首次运行误用要求同时存在训练集与开发集的校验器，在生成前中止。改用逐行校验，检查字段契约、原文片段和开发集角色，同时确认 8 条文本及 ID 各不相同。

三份权重的行为只覆盖同一来源的一种通知模板。观察到相邻地点文字变化伴随时间恢复，尚无法区分模型对这一措辞组合的敏感性与更普遍的跨字段漏抽。人工复核仍待完成。
