## 核心概念

- 最小对照固定活动和场地。更换未定措辞、交换分句和删除时间分句，分别对应不同的输入改动。
- 贪心生成记录模型实际给出的 JSON。目标前缀前向在已知正确前缀下读出下一 token 的分布，可以比较正确 token 与模型所选 token。
- 比较两条 token 序列时，先确认分歧来自字段值。空格、键顺序或引号也可能造成更早的 token 差异，字段对错仍按解析后的 JSON 判断。

### 2. 未定时间如何影响场地抽取

主对照的每一行有“会址”和“地点”两个版本。下表仅统计场地正确数，反向探针另计。

| 时间信息 | 分句顺序 | 36 步起点 | 统一称谓组 | 保留原称谓组 |
| --- | --- | ---: | ---: | ---: |
| 后续发布 | 时间在前 | 2/2 | 0/2 | 0/2 |
| 后续发布 | 地点在前 | 2/2 | 1/2 | 0/2 |
| 尚未确定 | 时间在前 | 2/2 | 0/2 | 0/2 |

加上反向探针，三份权重整条正确数依次为 15/15、10/15、7/15。统一称谓组漏了 5 个明确场地，保留原称谓组漏了 7 个场地和 1 个时间。45 份生成均符合 JSON 和字段契约，活动名均正确。5 条历史输入在三份权重上的 15 份输出逐 token 复现。[逐题结果](../../../practice/sft-extraction/results/2026-11-09-venue-omission-diagnostic-v1/review.json)

### 3. 目标前缀下的首个分歧

两组漏抽的 13 份输出都在相应字段的值刚开始时分歧。正确序列使用含字符串起始引号的 token，漏抽序列选了仅到冒号的 token，随后输出 `null`。以“会址、后续发布、时间在前”为例，统一称谓组的目标前缀前向给这两个 token 的概率约为 0.085 和 0.915，保留原称谓组约为 0.029 和 0.971。这里比较的是单个 token 的条件概率。[统一称谓组前向记录](../../../practice/sft-extraction/results/2026-11-09-venue-omission-diagnostic-v1/canonical-teacher.json) · [保留原称谓组前向记录](../../../practice/sft-extraction/results/2026-11-09-venue-omission-diagnostic-v1/target-teacher.json)

保留原称谓组有两条例外。对“地点在前、时间后续发布”的地点探针，目标前缀前向更偏向引号，概率约 0.562 对 0.437，贪心解码仍输出 `null`。反向时间探针也出现了这种差异，概率约 0.591 对 0.406。

### 4. 开关 KV cache 的复验

选上述两条例外和一条明显偏向 `null` 的对照，保留原称谓组各跑一次开启和关闭 KV cache 的贪心解码，共 6 次。开启 cache 的三份输出均逐 token 复现。六次输出在分歧位置之前使用同一前缀。表中概率依次对应正确的字符串起始 token 与开启 cache 时选中的冒号 token。

| 探针 | 开启 cache 的概率 | 关闭 cache 的概率 | 关闭 cache 后的字段 |
| --- | ---: | ---: | --- |
| 会址在后、时间后续发布 | 0.0293 / 0.9705 | 0.0293 / 0.9705 | 地点仍为 `null` |
| 地点在前、时间后续发布 | 0.4996 / 0.4996 | 0.5617 / 0.4374 | 地点恢复“松萝美工室” |
