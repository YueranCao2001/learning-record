# 2026-11-18：中文信息抽取微调：KV cache 对地点漏抽的影响范围

## 今日目标

检查“白榆印制室”之外的两组通知是否也会随 KV cache 开关改变抽取结果。完成条件是固定同一份权重，跑完三组通知、两种时间状态、两种提示与两种缓存设置，复现已有输出并记录发生变化的字段和首个 token。[上次单组复验](2026-11-17-sft-venue-location-token-trace.md)

## 核心概念

- 缓存开关在同一输入和提示下配对比较。关闭缓存时，生成每一步重新处理已有序列。两条路径都使用贪心解码，保留各自在实际生成步骤上的分数。
- 总分相等时仍要逐条比对。一个场地从漏抽变正确，另一个从正确变漏抽，两条变化会在总分里抵消。
- 输出共享前缀时，可以直接比较首个分歧位置的候选概率。这些概率表示该步的 token 选择，完整字段仍按最终 JSON 评分。

### 3. 三处变化都从地点值开头分歧

12 组配对中有 3 组生成 token 出现分歧，另 9 组完整 token 序列一致。三处首个分歧都出现在地点键名之后。候选 `3252` 含有字符串起始引号，`788` 对应闭引号与冒号，这三组中选中 `788` 后均继续生成 `null`。表中每格按 `3252 / 788` 列出概率。

| 通知与提示 | 首个分歧 token（从 1 计数） | 开启缓存 | 关闭缓存 |
| --- | ---: | ---: | ---: |
| 植物标本装帧课，原提示 | 16 | 0.4992 / 0.4992 | 0.5614 / 0.4372 |
| 蓝晒书签制作课，追加规则 | 16 | 0.4683 / 0.5306 | 0.5615 / 0.4373 |
| 木版套色体验，追加规则 | 15 | 0.6220 / 0.3773 | 0.4996 / 0.4996 |

植物标本课开启缓存时两候选得分持平，生成选择了 `788`，关闭后选择 `3252`。木版套色体验在关闭缓存后才出现两候选持平，这次生成选择了 `788`。完整输出及首个分歧的概率均已存档。[逐题对照](../../../practice/sft-extraction/results/2026-11-18-venue-cache-scope-v1/review.json)
